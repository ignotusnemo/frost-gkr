# Unequal-width Poseidon2b GKR benchmark

Date: 2026-08-11

## Environment

- CPU: 13th Gen Intel Core i7-1365U
- Logical threads used: 12
- OS: Linux 7.0.0-28-generic x86_64
- Rust: 1.96.0, LLVM 22.1.2
- Cargo profile: `release`, repository `-C target-cpu=native`
- Arithmetic backend: AVX2 + VPCLMULQDQ paired `GF(2^128)` products

## Statement

- Native Boolean widths: `[14, 15, 17, 16, 12, 15, 16, 12, 13]`
- Native physical rows: `360448`
- Max-padded physical rows: `1179648`
- Padding expansion: `3.2727x`
- Poseidon2b layers: `66`
- Committed field: `GF(2^128)`
- Sumcheck field: `GF(2^256)`

Each timed proof ran in a new worker process. The three variants rotated their
position in every sample round, with 20 seconds between workers. Every measured
proof was verified. The first sample of each variant also had a transcript
coefficient mutated, and the verifier rejected all three mutations.

Command:

```sh
cargo run --release --locked -p frost-gkr-bench --bin ragged -- \
  --warmups 0 --samples 3 --cooldown-seconds 20 --explain
```

## Direct observations

- Ragged versus independent prover median: `1.6260x` faster.
- Independent versus ragged algebraic transcript: `6.2558x` larger.
- Physical padding versus ragged row count: `3.2727x` larger.
- Fastest isolated physical-padding proof versus fastest isolated ragged proof:
  `3.0275x` slower.
- Maximum physical-padding process RSS versus ragged: `3.0017x` larger.

The independent path emits nine transcripts. The padded and ragged paths emit
the same one-walk proof shape. Their difference is physical prover work. Raw
algebraic proof bytes exclude serialization framing and external
polynomial-commitment openings.
